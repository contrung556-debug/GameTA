# Bé Vui English — Reborn

A **clean rebuild** independent from the old Flutter app and the previous Godot prototype.

## Why this restart?
The old versions tried to simulate polished 3D reference art using code-generated primitive shapes. This was not visually faithful. This new project explicitly separates **3D art slots** from **gameplay and UI**. The current meshes are intentionally temporary markers, not the finished look.

## Included now
- Godot 4.3+ standalone project, landscape layout, lighting and orthographic camera.
- Separate 3D art root with clear replacement slots for buildings and cat.
- Functional vocabulary mini-game for five locations.
- Persisted star rewards.

## Not included yet
- Production-quality rigged cat model, textures, animations and city meshes.
- Final polished 3D assets based on the reference images.
- Mobile IPA/APK export and on-device QA.

To run: open `be_vui_reborn/project.godot` in Godot 4.3+ and press F5. This is a **foundation build**, not a final 3D release.
